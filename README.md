# KanoHub

Digital Business Infrastructure for Kano — marketplace, merchant operating system, logistics, wallets, and financing (prototype).

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Use **Demo Mode** (bottom-right) to switch Customer / Merchant / Rider / Supplier / Admin / Executive.

Illustrative prototype data. Payment and financing screens are partner-powered concepts — not a licensed bank or lender.
